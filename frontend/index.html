                How to use RepoGraph

                1 · Analyze

                Click ＋ Analyze repo, paste a public repository link, start. When finished the Overview opens.

                2 · Overview

                Four plain sentences about the repository, its architecture layers, data model and the most used code.

                3 · Explore graph

                Shapes are code parts, arrows are relationships. Click anything to see its file, line and code. Double-click to focus. Use Find to jump to a name. Hide types with Show / hide.

                4 · Ask

                Ask in plain English. Each answer has tabs: Plain English, Developer, Cypher, How it was answered and Evidence.

                5 · Request flow

                Pick an endpoint: see each step from the HTTP request to the database table, with the code location of every step.

                6 · Impact

                Pick what you will change. You get a risk level, affected endpoints/code/tables, tests to run and possible side effects. It is a review checklist, not a guarantee.

                Shapes & colours

                Solid vs dashed arrows

                Solid = confirmed by the code. Dashed = probable (good evidence, not 100% proof). Click an arrow to read the reason.

                Answer labels

                ANSWERED from code evidence · NOT ENOUGH EVIDENCE exists but no proof of what you asked · CHOOSE ONE several matches · NOT FOUND no such name.
